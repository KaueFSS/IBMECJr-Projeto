# 🗄️ Comandos para Banco de Dados

> Execute os comandos diretamente da pasta `sistema_estoque`

### 🔐 Credenciais

| Campo | Valor |
|-------|-------|
| 👤 Username | `Usuario` |
| 🔑 Senha | `12345` |

### ▶️ Iniciar Servidor

```bash
python manage.py runserver
```
### ▶️ Cria migração
```bash
python manage.py makemigrations
```
### ▶️ Migra para o brando de dados
```bash
python manage.py migrate
```
